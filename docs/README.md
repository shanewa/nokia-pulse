# NokiaPulse documentation

NokiaPulse is a local-first Microsoft Edge extension for monitoring Nokia prices and setting browser price alerts. The default listing is Nasdaq Helsinki in EUR, not the NYSE ADR in USD.

## Documents

- [Project overview and local setup](../README.md)
- [Architecture](architecture.md): components, data flow, storage, and known limitations.
- [Privacy policy](PRIVACY.md): local data, external requests, permissions, and deletion.
- [Store listing](store-listing.md): English listing copy, permission explanations, and reviewer instructions.
- [Release review](store-review.md): validation and publishing checklist.

## Publishing status

These materials describe version 0.1.0. They are preparation materials, not confirmation of store approval or market-data licensing. Publisher account, public privacy-policy URL, support channel, screenshots, and distribution rights must be confirmed before submission.

All repository content is maintained in English. Recheck these documents whenever permissions, storage, data providers, or alert behavior change.
